## 需要在真实桌面复验的步骤

1. 启动“应用程序”中的橘子，收起使用说明。
2. 在 Finder 中按住 Shift 拖 PDF，移动约一秒，观察圆盘；拖入 JPG 扇区并松手，确认新 JPG 出现在原文件旁。
3. 按住 Shift + Option 拖 JPG，观察七个工具；释放 Option 应回到格式菜单，再按 Option 应回到工具。
4. 选择 Crop，拖动手柄，调整比例/像素，点击 Apply；再给裁剪结果 Add BG 并保存。
5. 试 Esc、中心松手、圆盘外松手，确认取消时没有生成文件。

入口只在支持文件的新拖拽会话中激活；裁剪手柄、文字选择和旧剪贴板内容不应弹出菜单。
