## 隐私与验收范围 / Privacy and acceptance

只使用专门制作的 `Citrus Demo` 文件；对外素材中没有工作桌面、文件选择器、最近文件列表、实际工作文件或私人绝对路径。参考视频和 Tangerine 原始素材没有上传。截图原始像素已做 OCR 与目视检查，两版视频共 1680 个时间点检查了文字及图片来源，完整视频做了解码和逐秒抽帧目视检查。详情见 [报告](MEDIA_VALIDATION.md)。

Only purpose-made `Citrus Demo` files appear. Outward media excludes the work desktop, file picker, recent items, actual work files, and private absolute paths. The reference clip and Tangerine assets are excluded. Source pixels were reviewed with OCR and visual inspection; text/image provenance was checked at 1680 video frame timestamps, and encoded videos received full decode and one-frame-per-second visual checks. See the [report](MEDIA_VALIDATION.md) for exact scope.

Finder Shift / Shift+Option 真实操作仍待使用者复验。演示从已实际验证的“选择文件…”进入，不将圆盘激活画面算作 Finder 手势验收。

Physical Finder Shift / Shift+Option gestures remain pending user retest. The demo uses the verified file-picker entry and does not establish Finder gesture acceptance.
